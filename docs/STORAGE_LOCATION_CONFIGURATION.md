# 统一数据目录配置

后台进程启动时读取 `FIELDWORK_DATA_DIRECTORY`。未设置时继续使用项目 `data/`；显式设置无效时停止启动，不回退到默认数据库。

配置目录必须已存在，为当前用户所有且 POSIX 权限不向组或其他用户开放（例如0700）；使用绝对路径，路径及其父目录不能是符号链接。数据目录配置在进程内固定，改环境变量不能热切换。

数据库、证据、仓库、报告导出、Agent工作区、Web3练习结果、本地凭据、扩展包、备份及监控服务均使用统一目录。独立监控启动仍显式绑定当前数据库与数据根路径。

这是目录配置能力，不自动复制或修改旧数据。配置一个空目录会初始化独立数据库。正式迁移流程仍需备份、全部写入者停机、路径记录重映射、完整复制校验、原子切换及回滚验收。现有数据库中的绝对文件URI不会因本配置自动改写；不能仅复制数据库并声称迁移成功。

原生 App 启动子进程继承启动环境；目前尚未提供 Finder 启动使用的持久目录切换设置。UI目录检查不写入此配置。钥匙串、应用包与源码不由本配置搬迁。
