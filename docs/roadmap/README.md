# 开发路线图

本文列出当前工作的主要方向。功能实现、隔离测试、原生安装与发布验收分别记录，不以测试数量作为完成百分比。

| 方向 | 已有基础 | 后续工作 |
| --- | --- | --- |
| 研究工作流 | 三域入口、候选、任务、图谱、回执与报告 | 真实授权输入到修复复测的完整质量验证 |
| 编排与模型 | 持久租约、角色与并发控制、路由、预算与用量对账 | 多角色对比基准、真实运行恢复和成本/证据增益评估 |
| Agent Audit | 离线导入、策略重建、对账与事件证据包 | 采集器安装、覆盖边界和完整端到端验收 |
| 存储维护 | 备份、恢复演练、协作锁、暂存与部分引用重映射 | 完整离线切换、启动及回滚验收 |
| 发布与供应链 | 平台运行锁、Python SBOM、源码关联 App | 全部依赖与工具来源、项目许可证、独立打包与发布门 |

详细条款位于开发分支的 [Master Bundle 范围审计](https://github.com/haipi001/fieldwork/blob/codex/v6-final-control-plane/docs/roadmap/MASTER_BUNDLE_PROGRESS_AUDIT_2026-10-04.md) 与 [UI/核心交付计划](https://github.com/haipi001/fieldwork/blob/codex/v6-final-control-plane/docs/roadmap/V5_UI_AND_CORE_DELIVERY_PLAN_2026-10-04.md)。

历史状态与测试结果见[文档归档](../archive/README.md)及[验收索引](../acceptance/README.md)。具体记录仅描述其对应版本、环境和验证范围。
