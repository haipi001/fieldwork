# AI Agent Security 固定监控入口

用户要求：AI Agent Security 应作为左侧固定监控页面，不通过新建研究发起。

本轮实现：
- Sentinel 导航改为 AI Agent Security，保留原路由和历史审计。
- 新建研究移除 Agent 选项；监控页和 Agent 域隐藏新建按钮，域选择可跳转监控页。
- 独立读取当前非 demo 的 desktop 活动/暂停监控，不使用历史审计选择作为操作目标。
- 显式启用、暂停、恢复、立即采集；页面打开及轮询只读，失败后禁用写操作并要求刷新。
- 显示采集延迟、降级、错误与最近采集时间。说明退出 App 后停止、采集不等于漏洞确认。
