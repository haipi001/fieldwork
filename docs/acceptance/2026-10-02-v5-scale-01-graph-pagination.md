# V5-SCALE-01：跨页研究关系完整读取

版本：0.65.0 / Build 74 / Schema 24。

## 问题与行为

旧 `/research/campaigns/{id}/graph` 返回当前节点页的诱导子图：只有两端都在该页的边才返回。遍历所有节点页仍会丢掉跨页支持、反证与谱系关系；首页和研究图谱页还只读首 200 个节点。

新增 `/api/v1/research/campaigns/{id}/graph/page`，同时但独立分页节点和边。每次每类默认 200 项、最多 1000 项；一类读完后继续读取另一类，返回 `nodes_complete`、`edges_complete`、`has_more` 和 `next_cursor`。游标绑定 Campaign，以 `created_at,id` 定位，非法/跨 Campaign 游标返回 422。Canonical 节点仍逐项复核当前 Receipt 信任状态。旧诱导子图接口保留原合同供旧调用方使用。

首页和研究图谱页切换至新接口，显式继续加载；前端保留尚未出现端点的关系，端点到达后显示。页间重复记录去重，读取失败保留当前图谱并允许原游标重试。切换项目/模式后迟到请求不替换新视图；首页原先会提前覆盖共享图谱变量的问题一并修复。

这是逐请求读事务中的实时分页，不是跨请求数据库快照。读取过程中新增到游标之前的记录、已读节点的更新/删除需要刷新；未找到端点的关系会明确计数，不能将残缺图谱称为完整事实。当前没有整图响应大小/渲染延迟的性能保证。
