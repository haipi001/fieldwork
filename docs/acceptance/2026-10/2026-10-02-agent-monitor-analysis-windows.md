# AI Agent Security 增量分析窗口

目标：持续采集不得被一次整会话 analyze 冻结；新事件应进入可恢复、不可变的分析输入。

实现：
- 每次后台 tick 最多处理 200 个未分析事件（内部最大 500），事务内写入窗口 Artifact 和唯一事件归属；重复调用无新事件不产出窗口。
- 窗口保留策略/身份/Scope 快照、原始事件与来源字段、证据引用、输入摘要、规则版本和确定性策略分析结果。
- 缺少 PolicySnapshot 明确为 policy_required；线索保持 not_verified，不创建 Canonical Finding，不代表独立漏洞复验。
- 活动和暂停监控禁止整审计 analyze；停止后的原流程保留。
- 分析失败不停止采集；持久记录错误类型和指数退避，下次成功清理错误。窗口读取验证 Artifact hash 与输入 digest。
- 监控页显示最近窗口、待分析数、缺少策略或重试状态；窗口 API 不可用不被当作没有异常。

验证：Agent Audit 56 项测试通过，含继续导入、不重复分析、四线程唯一归属、策略正例仅产出线索、缺策略未知态、失败退避恢复和 Artifact 篡改拒绝。浏览器隔离验证当前页面与控制流程。均未对外扫描或启动真实桌面采集。

限制与下一步：当前只做记录行为的策略分析，不做自述完整性推断或自动独立复验；当前默认 monitor 没有策略，需接入配置和版本化策略切换。仍需独立后台、窗口复验任务、失败/恢复长时测试、告警和实际安装版全链验收。源代码已更新；本轮尚未重启现有后台加载新接口，不声称已运行部署验收完成。
