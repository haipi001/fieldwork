# 统一事件流增量

在保留原有单 Run 视图、18 页导航及其他工作台功能的基础上，扩展运行事件页：

- 汇合 Run 事件、V5 调度/模型/工具事件和 Agent Audit/监控遥测。
- 项目、来源和任务 ID 筛选在后端执行，保留分页；按时间和事件 ID 确定顺序。
- 模型调用/路由、工具执行与策略判定使用数据库外键记录关联任务及 Run；不存在或跨 Campaign 冲突的关联保持空，不从自由文本载荷推断关联。
- 监控记录显示产物 ID、Run 证据入口和演示标记；不向统一列表暴露原始遥测载荷。V5 自由载荷也不直接返回。
- Run 类型仍代表 Run 自身记录，包括旧工具链在 Run 中记录的事件；工具来源表示 V5 工具执行事件。统一列表不是漏洞成立或监控完整覆盖的证明。
