# 运行与维护

本指南适用于当前开发分支。环境准备见[快速开始](getting-started.md)。

## 启动与会话

日常从 Fieldwork 桌面 App 启动。应用创建会话并绑定本地后台实例；普通浏览器直接访问服务地址不会自动取得桌面 Cookie。CLI 维护客户端需显式配置 `FIELDWORK_SESSION_TOKEN` 并通过请求头传递，凭据不得进入公开日志或问题报告。

## 工具与模型

通过工作台查看工具可用状态，配置模型 Provider 后先验证连接，再检查路由、预算和研究范围。可选 Agent 还需其各自运行环境。缺少工具、提供方不可用或策略拒绝的任务应保留相应状态，不按成功处理。

## 数据与恢复

默认数据目录为 `data/`。显式目录配置在进程启动时读取；设置空目录会创建独立数据环境，不能替代已有数据迁移。当前目录规则见开发分支的[存储配置](https://github.com/haipi001/fieldwork/blob/codex/v6-final-control-plane/docs/guides/STORAGE_LOCATION_CONFIGURATION.md)。

使用工作台的备份与隔离恢复演练检查可恢复性，保留备份清单和摘要。升级备份、证据备份、凭据管理和源码版本各有不同范围。正式替换、迁移和回滚前，需满足对应工具的停机与兼容性检查；不要直接替换正在使用的数据库。

出现启动失败时保留脱敏日志、应用版本及提交 SHA。优先检查会话/实例、端口、依赖环境和数据库兼容性；不要通过清空业务数据或关闭验证约束解决问题。
