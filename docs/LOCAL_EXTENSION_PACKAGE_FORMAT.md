# 本地扩展包格式

ZIP 必须含 `fieldwork-extension.json` 和清单指定的入口文件。示例：

```json
{
  "id": "example-pack",
  "name": "Example research pack",
  "version": "1.0.0",
  "type": "pack",
  "entrypoint": "entry.py",
  "capabilities": ["network.request"]
}
```

字段必须恰好为上述六项，type支持pack/mcp/adapter。ID限小写字母、数字、下划线和连字符，首字符为字母。包和解压总量上限4 MiB、最多64个普通文件；不接受加密、链接、特殊文件、重复路径、目录记录、绝对路径或路径穿越。允许ZIP Stored/Deflate，清单禁止重复键。能力仅是声明，不产生授权。

扩展页选择本地ZIP、填写预期小写SHA256、预检清单/当前版本，再明确确认保存。更新要求当前版本摘要一致；历史按50条分页，可回到保存的旧版本，仍保持禁用。当前包最多128个、版本归档最多500份，超限拒绝且不自动删除旧版本。

包存在私有版本库，未解包、未执行、未建立发布者信任。清单SHA256验证传输和版本身份，不能证明来源可信。读取时重新检查归档字节及对应审计记录，缺失/损坏/未提交的记录显示存储未确认。第三方运行适配、签名信任、权限启用、自动更新和存储保留治理仍未完成。新版数据库与证据备份会包含这个包版本库并校验指针、归档及审计关联；旧格式备份不包含包库。总量仍受512 MiB备份上限约束，超限拒绝，不会静默少备份。正式替换/迁移尚未实现，隔离恢复演练不覆盖当前包库。
