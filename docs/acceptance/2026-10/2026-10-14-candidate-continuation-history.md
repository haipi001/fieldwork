## 实现范围

首页候选下一步接入“一键继续深挖”，在当前 Run 上复用既有 guided-research：一次确认后整理材料、按已授权范围读取适用页面、对支持的对象读取候选执行独立复验，最多连续 50 轮。身份、业务规则、证据、验证器与预算缺项明确保留；不自动推定影响或晋升 Finding，不自动提交报告。此入口不是全领域自主漏洞挖掘或新增通用 AI 推理引擎。

连续任务轮询跟随当前运行的最新批次，结束时自动读取仅属于该 Run 的结果摘要：确认发现、待确认候选、证据数量、候选状态和处理历史。后端聚合使用只读事务，避免其他 Run 或项目混入。停止按钮取消整个 Run 的连续处理，自动接力绑定父任务并在同一写事务里核对取消状态，防止已停止的终态批次继续启动。

项目选择以实际显示上下文单独跟踪，避免其他页面修改 activeEngagement 后绕过清理。切换或新建目标会清空旧 Run/候选/报告详情与迟到请求，任务、结果、候选、回执及事件/证据查询默认限定当前目标。历史全局总览默认隐藏，可通过“历史项目”入口主动打开，原功能保留。

设置页增加“清除所有记录”。先显示记录数量，再要求输入 DELETE ALL。后端拒绝活动研究、队列/租约、复验、监控、调度、未结清模型调用及导入任务；独立监控使用管理/运行锁。删除阶段独占 API 写入入口，普通任务取消和配置修改保持并发，不等待模型传输结束。

全量清除删除研究表、V5/V6 研究/安全/用量历史、已管理研究文件、合约导入、练习结果、报告和当前数据目录内备份，保留模型 Provider/Profile、节点/智能体组件配置和已安装工具。不会清理用户自行复制到其他目录的文件；已登记证据在管理根目录外时阻断。事务中暂时移除研究表的不可变触发器，清除后按原 SQL 恢复，并核对外键。文件先在根目录内暂存，数据库提交前失败恢复原目录；提交后文件/所属会话钥匙串清理失败明确返回未完成，保存清理义务供再次清除重试，不报告成功。此删除不声称对系统快照或存储介质完成取证级擦除。
